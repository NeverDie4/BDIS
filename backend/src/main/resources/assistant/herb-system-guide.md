# 生物医药数字信息系统使用说明

## 1. 系统定位

本系统用于中药材图谱识别、采集任务管理、批次档案管理和识别结果复核。系统面向 PC 端管理人员和手机端采集员，支持从标准图谱维护、现场采集、图片上传、自动识别到人工复核和批次归档的完整流程。

## 2. 单张图片识别流程

单张图片识别流程为：上传采集图片 -> 提取图片特征 -> 本地图谱匹配 -> 低置信度时豆包辅助识别 -> 生成最终识别结论 -> 人工复核。系统会优先使用本地标准图谱库进行匹配，识别置信度不足或结果需要补充判断时，再使用豆包辅助识别作为文本和视觉识别参考。

## 3. 标准图谱库说明

标准图谱库用于保存中药材标准图谱、药材基础信息、特征数据和识别参考信息。标准图谱是本地图谱匹配的主要依据，图谱质量会影响图片识别准确性。维护标准图谱时，应尽量保证图片清晰、药材类别准确、基础信息完整。

## 4. 采集图片说明

采集图片是现场拍摄或上传的中药材图片。上传后，系统会保存图片并触发识别流程。采集图片应尽量保证光线充足、主体完整、背景干扰少、药材纹理清晰。图片质量差、遮挡明显或药材主体不完整时，识别结果可能需要人工复核。

## 5. 采集任务说明

采集任务用于组织一次或多次中药材现场采集工作。批次采集流程为：PC 端创建采集任务 -> 手机端查看任务 -> 新建批次 -> 拍照上传图片 -> 自动绑定批次 -> 触发识别 -> 刷新批次汇总 -> 提交批次 -> PC 端确认归档。任务可以关联多个批次，批次中可以绑定多张采集图片。

## 6. 批次档案说明

批次档案用于记录同一次采集或同一批药材的图片、识别结果、复核状态和汇总评价。批次档案可以帮助管理人员集中查看本批次的采集情况、识别完成情况、主要药材判断和质量评价结果。

## 7. 手机端使用流程

手机端采集流程为：采集员登录或进入手机端采集页面 -> 查看分配的采集任务 -> 新建或进入批次 -> 拍照或选择图片上传 -> 图片自动绑定到批次 -> 等待系统识别 -> 查看识别状态 -> 必要时补拍或提交批次。提交后，PC 端管理人员可以进行确认、复核和归档。

## 8. 人工复核规则

出现以下情况时建议人工复核：低置信度、识别结果不一致、豆包结果与本地图谱结果不一致、图片质量差、图片主体不清晰、药材类别存在争议、批次主要药材占比异常等。人工复核用于确认最终识别结论，避免自动识别误判直接影响批次归档。

## 9. 批次汇总评价规则

批次质量评价会根据图片数量、已识别数量、复核状态、平均置信度、主要药材占比等信息生成质量等级和评价摘要。图片数量充足、识别完成率高、平均置信度高、主要药材占比稳定且复核通过时，批次评价通常更好。若存在大量未识别图片、低置信度图片或复核未完成记录，应先补充采集或完成复核。

## 10. 常见问题

### 这个系统是干什么的？

系统用于管理中药材采集、图片上传、图谱识别、批次档案和人工复核流程，帮助用户形成可追溯的中药材识别记录。

### 怎么进行中药材采集？

通常先在 PC 端创建采集任务，再由手机端采集员进入任务，新建批次，拍照上传图片，等待系统识别并提交批次。

### 怎么上传图片？

可以在采集流程中拍照或选择图片上传。上传后图片会绑定到对应批次，并进入识别流程。

### 怎么识别图片？

图片上传后，系统会进行特征提取和本地图谱匹配。低置信度或需要辅助判断时，可以使用豆包辅助识别，最后生成识别结论。

### 什么情况下需要人工复核？

低置信度、结果不一致、豆包辅助识别与本地图谱结果不一致、图片质量差或药材类别存在争议时，需要人工复核。

### 批次档案是什么？

批次档案是同一批次采集图片、识别结论、复核状态和汇总评价的集合，用于后续查看、确认和归档。

### 手机端怎么使用？

手机端主要用于采集员查看任务、创建批次、拍照上传、查看识别状态和提交批次。

### 图谱识别和豆包辅助识别是什么关系？

本地图谱识别是系统优先使用的识别方式，基于标准图谱库进行匹配。豆包辅助识别是补充判断手段，通常在低置信度或结果需要辅助参考时使用，不能替代最终人工复核。
