M01–M04 的 90、99、93、17 均按当前前端公式预计算：海拔接近度 35%、18 km 内点位密度 35%、最新生长阶段 30%。

路线是页面运行态并依赖公共 OSRM。必演内容定为点位路线规划和预览；实时定位导航只有在浏览器定位与现场网络均可用时才演示。

采集审核与科研证据

P04 的生长记录可以业务审核通过，同时保留图片识别待复核和科研证据不足；两者属于不同层次，不冲突。

Agent 补采数据归属

P10–P12 用于 Agent 等待条件和重新分析，不会自动成为 P01 公开档案的新阶段；公开页只展示 P01 已审核阶段。

申报“归档”状态

当前实现审核通过后生成档案袋：申报为 approved，档案袋为 generated。总表不再把它写成申报 archived。
