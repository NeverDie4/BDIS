## 1. 文档目的

本文档将任务清单、需求分析、模块设计、数据库设计和接口设计转化为可直接执行的后端开发任务，明确：

1. 四个模块的业务边界与依赖关系；
2. 推荐的后端包结构和类清单；
3. 每个模块的开发任务、测试任务和完成标准；
4. 数据库、接口、权限、文件、审计等公共能力的接入方式；
5. 开发顺序、联调顺序和最小可交付闭环。

本文件不替代《04_接口设计说明书》和《05_数据库详细设计说明书》。数据库及接口缺口见配套文件《04-05_M12-M15_数据库与接口补充设计》。

## 2. 模块范围与优先级

| 模块 | 优先级 | 单一职责 | 最小完成标准 |
|---|---:|---|---|
| M12 实验课程 | P0 | 管理课程、实验步骤、课程资源、视频链接和发布状态 | 教师可维护课程，学生可查看已发布课程及资源 |
| M13 课题研究 | P1 | 管理课题、成员、研究周期、关联药材、过程材料和阶段成果 | 科研人员可创建课题、绑定成员并上传研究材料 |

| M15 培训过程 | P1 | 管理培训计划、素材、参与人员、进度结果和反馈 | 可完成计划、学员、结果、反馈的完整链路 |

### 2.2 依赖约束

- M12 不保存学生实验过程，实验过程由 M14 管理。
- M13 不保存具体实验笔记，实验笔记由 M14 管理。
- M14 只引用课程 ID 或课题 ID，不修改课程、课题主数据。
- M15 可选关联 M12 的课程，但培训计划、参与记录和反馈独立保存。
- 所有附件先进入 M05 文件资源模块，再通过业务关联表或业务扩展表绑定。
- 所有写操作接入 M06 操作审计，关键状态变化同时记录数据变更日志。

### 3.2 分层职责

| 层次 | 职责 | 禁止事项 |
|---|---|---|
| Controller | 接收参数、校验、调用 Service、返回统一响应 | 不写 SQL，不处理复杂事务 |
| Service | 业务校验、状态机、事务、跨表协调、权限和文件关联 | 不直接拼接 HTTP 响应 |
| Mapper | 单表 CRUD、分页、复杂查询 | 不处理业务状态 |
| Entity | 对应数据库字段 | 不直接作为接口请求或响应对象 |
| DTO | 新增、修改、提交、归档等输入 | 不暴露数据库审计字段 |
| Query | 分页、筛选、排序条件 | 不携带写操作字段 |
| VO | 前端展示数据 | 不返回密码、内部规则等敏感字段 |
| Converter | Entity、DTO、VO 转换 | 不承载业务流程 |

### 7.2 状态机

```text
draft → submitted → archived
  │         │
  └─────────┘ 允许退回 draft，需记录原因
```

本期最小闭环可简化为：

```text
draft → submitted → archived
```

状态规则：

- `draft`：创建人可修改、删除、绑定附件；
- `submitted`：正文冻结，可由有权限人员退回或归档；
- `archived`：不可修改、不可删除，只允许查询和下载附件。

## 9. DTO、VO 与查询对象设计原则

### 9.1 DTO 分离

新增和修改 DTO 不共用一个类，避免修改接口误覆盖不可变字段。

示例：

```text
CourseCreateDTO 允许 courseNo
CourseUpdateDTO 不允许修改 courseNo
ExperimentRecordArchiveDTO 只包含 archiveComment
TrainingRecordUpdateDTO 只包含 attendanceStatus、progress、trainingStatus、score
```

### 9.2 VO 聚合边界

- 列表 VO 只返回表格展示字段，避免每行查询完整附件。
- 详情 VO 才聚合成员、步骤、资源和附件。
- 用户、药材、课程等关联对象返回摘要，不直接返回完整 Entity。

### 9.3 Query 统一分页字段

所有 Query 继承或组合：

```text
pageNo
pageSize
sortField
sortOrder
```

业务筛选字段：

| Query | 主要筛选条件 |
|---|---|
| CourseQuery | keyword、courseType、teacherId、publishStatus、时间范围 |
| ResearchProjectQuery | keyword、projectType、leaderId、speciesId、projectStatus、时间范围 |
| ExperimentRecordQuery | keyword、sourceType、courseId、projectId、recorderId、archiveStatus、时间范围 |
| TrainingPlanQuery | keyword、planType、ownerId、publishStatus、时间范围 |
| TrainingRecordQuery | planId、userId、attendanceStatus、trainingStatus |

## 10. 事务边界

以下操作必须使用事务：

| 业务操作 | 事务内容 |
|---|---|
| 新增课程 | 课程主表、步骤批量保存、资源绑定 |
| 发布课程 | 发布状态、发布人时间、审计日志 |
| 新增课题 | 课题主表、负责人成员关系、初始材料绑定 |
| 成员变更 | 关系状态更新、变更日志 |
| 新增实验记录 | 主记录、附件绑定 |
| 提交或归档实验 | 状态更新、时间操作者、日志 |
| 新增培训计划 | 计划主表、课程关联、素材绑定 |
| 批量添加学员 | 参与记录批量插入、重复检查 |
| 提交培训反馈 | 反馈写入、参与记录状态校验 |

事务方法放在 Service 实现类，避免在 Controller 中使用 `@Transactional`。
