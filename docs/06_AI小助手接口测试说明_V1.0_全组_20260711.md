# AI 小助手接口测试

本文档用于在前端登录页完成前，直接通过 Windows PowerShell 测试后端 AI 小助手。

## 前置条件

1. 启动后端：

```powershell
cd D:\BDIS
pnpm dev:api
```

2. 执行数据库迁移：

```powershell
cd D:\BDIS
pnpm db:migrate
```

3. 建议启动 Redis。若本地 Redis 暂不可用，后端会跳过 token 黑名单检查，但生产环境仍应启用 Redis。

```powershell
cd D:\BDIS
docker compose up -d redis
```

4. 检查 `.env` 中真实 AI 配置：

```properties
HERB_ASSISTANT_ENABLED=true
HERB_ASSISTANT_MOCK_ENABLED=false
HERB_ASSISTANT_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
HERB_ASSISTANT_MODEL=doubao-seed-2-1-pro-260628
HERB_ASSISTANT_API_KEY=你的 API Key
```

修改 `.env` 后需要重启 `pnpm dev:api`。

## PowerShell 编码

```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

```

## 初始化管理员

只需要执行一次。若返回 409，表示管理员已存在，可以直接登录。

```powershell
$body = @{
  bootstrapToken = "change-me-bootstrap-token"
  username = "admin"
  password = "Admin123456"
  realName = "系统管理员"
} | ConvertTo-Json -Compress

Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/auth/bootstrap-admin" `
  -ContentType "application/json; charset=utf-8" `
  -Body $body
```

## 登录并保存 Token

```powershell
$loginBody = @{
  username = "admin"
  password = "Admin123456"
} | ConvertTo-Json -Compress

$login = Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:8080/api/auth/sessions" `
  -ContentType "application/json; charset=utf-8" `
  -Body $loginBody

$token = $login.data.accessToken
$headers = @{ Authorization = "Bearer $($token.Trim())" }
```

## 查看完整 UTF-8 JSON

```powershell
$response = Invoke-WebRequest `
  -Method Post `
  -Uri "http://localhost:8080/api/herb/assistant/chat" `
  -Headers $headers `
  -ContentType "application/json; charset=utf-8" `
  -Body $chatBody

$stream = $response.RawContentStream
$stream.Position = 0
$reader = New-Object System.IO.StreamReader($stream, [System.Text.Encoding]::UTF8)
$reader.ReadToEnd()
```

## 常见问题

- `409 冲突`：管理员已经初始化，直接登录即可。
- `UNAUTHORIZED`：重新登录获取 token，并确认请求带了 `Authorization: Bearer <token>`。
- `RedisConnectionFailureException`：Redis 未启动。开发环境会降级跳过黑名单检查，生产环境应启动 Redis。
- `AI 模型 baseUrl 未配置`：检查 `.env` 并重启后端。
- `AI 模型调用失败`：查看后端日志中的 `Ark Responses HTTP error`，确认 endpoint、model、额度和 API Key。
- PowerShell 中文乱码：执行本文档的编码命令，或使用 PowerShell 7、Postman、Apifox 测试。
