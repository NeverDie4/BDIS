现场切换原则

  1. 答辩前分别打开三个 Chrome 个人资料窗口并完成登录。
  2. 三个窗口放在固定桌面位置，不在同一个人资料里反复退出和登录。
  3. 每次切换前通过 Chrome 个人资料颜色和系统右上角用户名双重确认角色。
  4. 建议按“教师 → 采集员 → 审核员 → 教师”的节奏切换，关键页面提前打开。
三个 Chrome 个人资料是三套独立登录环境；这是现场演示组织方式，不是系统内的“角色一键切换”功能。

04 · SPEAKING BOUNDARIES

答辩讲解口径

下列边界用于确保演示表述与当前系统能力一致。

地图与任务

说“地图辅助选点和规划路线，教师据此建立任务”；不说“地图路线自动生成系统任务”。

适生分析

说“基于现有观测数据的辅助分析”；不把轻量评分表述为经农学验证的预测模型。

AI 小助手与 Agent

AI 小助手负责知识问答和流程解释；科研 Agent 负责具体任务的持久分析、证据缺口、计划和待确认动作。

Agent 不自主执行高风险动作

创建补采任务和开启公开档案分别需要一次教师确认，突出人机协同与权限边界。

补采证据的归属

补采任务数据参与 Agent 重新分析，但不宣称其作为新阶段出现在原任务公开页。

公开档案内容

公开页展示原任务已审核且可公开的阶段、图片、趋势、地图、解说和完整性校验；不宣称展示完整 Agent 闭环结论。
