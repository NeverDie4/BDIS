# 生长记录溯源码与二维码

## 模块说明

本模块为 `herb_growth_record` 增加溯源码、二维码和公开溯源查询能力。管理端可以生成溯源码、生成二维码、开启或关闭公开溯源；公开接口无需登录，但只允许访问 `public_visible = 1` 的生长记录。

## 数据库字段

新增字段位于 `herb_growth_record`：

- `trace_code`：溯源码，允许历史数据为空。
- `trace_qrcode_url`：二维码图片地址。
- `trace_public_url`：公开访问路径，格式为 `/trace/growth/{traceCode}`。
- `public_visible`：是否公开溯源，默认 `0`。
- `trace_generated_time`：溯源码生成时间。
- `trace_generated_by`：生成操作人 ID。
- `trace_generated_by_name`：生成操作人名称。

`trace_code` 使用唯一索引 `uk_growth_record_trace_code`，MySQL 允许多条历史记录的空值。

## 接口列表

- `POST /api/growth-records/{id}/trace-code/generate`：生成或返回已有溯源码。
- `POST /api/growth-records/{id}/trace-qrcode/generate`：生成二维码；没有溯源码时会先生成。
- `GET /api/growth-records/{id}/trace-qrcode`：查询二维码和公开状态。
- `PUT /api/growth-records/{id}/trace/public-enable`：开启公开溯源。
- `PUT /api/growth-records/{id}/trace/public-disable`：关闭公开溯源。
- `GET /api/trace/growth/{traceCode}`：公开查询生长记录溯源档案。

## 权限说明

管理端接口仍需登录，并以后端当前用户和数据范围为准。

- `ADMIN`、`REVIEWER`、`TEACHER`：在有数据访问权时可生成溯源码、二维码并开关公开溯源。
- `COLLECTOR`：可查看自己记录的二维码信息和公开状态，不能越权操作他人记录或开关公开。
- 公开查询接口不需要登录，只返回公开记录。

## 二维码生成逻辑

溯源码格式为 `TRACE_GROWTH_yyyyMMddHHmmss_随机数`。二维码内容是完整公开访问 URL，例如 `${bdis.trace.public-web-base-url}/trace/growth/{traceCode}`。二维码 PNG 保存到配置的文件存储目录下：

```text
{bdis.file.storage-path}/trace/qrcode/
```

接口返回的二维码地址为：

```text
/api/growth-records/{id}/trace-qrcode/content（管理端鉴权访问）
/api/trace/growth/{traceCode}/qrcode（公开后匿名访问）
```

二维码通过专用受控接口读取，不开放通用文件目录。

## 公开查询逻辑

公开接口按 `traceCode` 查询生长记录：

- 溯源码不存在：返回友好错误。
- `public_visible = 0`：返回“该溯源档案暂未公开”。
- `public_visible = 1`：返回公开档案。

公开档案只返回业务展示字段，不返回 JWT、手机号、内部权限字段等敏感信息。现场图片来自当前生长记录绑定 `batchId` 下的 `herb_batch_image` 和 `herb_image`。

## 溯源事件类型

- `trace_code_generated`：生成溯源码。
- `trace_qrcode_generated`：生成溯源二维码。
- `public_trace_enabled`：开启公开溯源。
- `public_trace_disabled`：关闭公开溯源。

以上事件写入 `herb_growth_trace_event`，不影响已有事件类型。

## 测试流程

可执行服务层测试：

```powershell
mvn -f backend/pom.xml test
```

也可在后端服务和数据库正常运行后执行接口脚本：

```powershell
pnpm.cmd test:growth:trace
```

脚本流程包括管理员登录、选择一条生长记录、生成溯源码、生成二维码、查询二维码信息、开启公开、公开查询、关闭公开、确认公开查询被拒绝、校验溯源事件。

## 注意事项

- Web 管理端提供二维码与公开开关操作，公开档案页位于 `/trace/growth/{traceCode}`；手机端主流程不受影响。
- 不新增 `archived` 状态，也不改变已有审核状态流。
- 公开访问只受 `public_visible` 控制，不要求登录。
- 二维码文件不保存到源码目录。
- 如果历史记录没有 `trace_code`，只有在调用生成接口时才写入。
