生物医药数字信息系统总体用例图与功能域说明

根据粗功能分解图调整总体用例图，突出参与者、系统边界、六大功能域和核心用例之间的关联。

一、总体用例图

矩形内为系统边界和业务用例，外侧为教师、学生、科研人员、采集端、评价申报人员、业绩审核人员、管理员和外部系统。
绘图说明：小人表示参与者，矩形表示系统边界，内部浅色分区表示功能域，椭圆表示用例。关联线连接到代表性用例椭圆边缘，并控制数量以避免覆盖文字；具体用例归属由功能域分区体现。用例名称已按粗功能分解图统一。

二、功能域用例说明表

表格与上方用例图保持一致，面向需求分析阶段说明每个功能域的参与者、能力点和输出。
编号 功能域 主要参与者 核心用例 / 能力点 主要业务结果 异常或扩展
FD-01 中药材资源与生长数据管理 教师、学生、科研人员、科研机构、采集人员、手机 APP、校内 SOAP 系统 重庆市中药材分布网络地图；生长数据采集与存储；校内系统与手机端通信；图谱比对、数据分析与溯源。 形成可查询、可分析、可溯源的中药材资源、生长数据、图片文件和接口交换记录。 网络异常时支持移动端暂存后同步；接口失败时记录日志并重试；无匹配数据时提示无结果。
FD-02 教学科研资源管理 教师、学生、科研人员、科研机构、系统管理员 实验课程存储；线上教学资源；课题研究存储；成果转化支撑。 课程、课件、视频、文档、课题过程材料和成果转化记录被统一维护、查询和归档。 资源上传失败时提示重试；课题成员或成果材料变更时保留历史记录和版本信息。
FD-03 教学培训过程管理 教师、培训人员、学生、学员 培训素材制作与存储；教学培训过程记录；教学培训结果记录；培训资料复用。 形成培训素材、安排、参与情况、学习过程、考核结果和反馈评价的完整档案。 缺勤、未完成、补考或补交反馈可作为扩展记录处理；资料可按权限查询和复用。
FD-04 评价体系与申报管理 评价管理人员、专家、教师、科研人员、申报人员 中药材评价体系；评价过程跟踪；申报素材管理；评价结果归档。 评价指标、规则、任务、过程记录、申报数据和佐证材料可追踪、可统计、可归档。 评价标准变更时保留版本；申报材料缺失时提示补充；评价结果按权限开放下载。
FD-05 工作业绩认定管理 教师、科研人员、业绩填报人员、审核人员、管理人员 工作业绩录入与编辑；业绩审核与认定；分级分类统计；认定标准维护。 形成业绩填报材料、审核记录、认定结果和按学校标准统计的分级分类报表。 材料不符合要求时退回修改；认定标准更新后按版本进行认定和历史追踪。
FD-06 用户管理 系统管理员、教师、学生、科研人员、培训人员、机构用户、外部系统账号 用户账号管理；角色权限管理；层级管理；访问与操作记录。 为各类用户提供账号、角色、菜单、功能、数据范围、文件访问和审计记录支撑。 认证失败时拒绝访问；权限不足时隐藏功能或提示无权限；关键操作进入审计记录。
后续详细设计时，可在每个功能域下继续补充触发条件、输入输出字段、权限矩阵、接口清单和数据字典。
