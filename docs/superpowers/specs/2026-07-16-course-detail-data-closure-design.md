# 课程详情数据闭环设计

## 目标

修复课程编辑后详情页显示默认空值的问题，并使课程详情中的课程资源、视频资源和关联信息均展示真实已保存数据。教师与管理员可以编辑本人可管理的课程；学生保持只读。

## 已确认的业务规则

- 先修课程从现有课程中多选，只显示已发布、未下线课程，且编辑时排除当前课程。
- 课程标签采用可输入、可删除的标签控件，不再使用按行填写的文本域。
- “课程资源”只显示普通课程文件；“视频资源”只显示课程视频并支持播放。
- 关联信息可选择已有中药材与已有课题，并展示课程已保存的关联项。
- 编辑入口与写接口使用既有 `edu:course:update` 权限；后端继续用课程归属校验保证教师只能编辑本人创建或负责的课程，管理员可编辑全部课程。

## 根因

课程创建和更新请求已包含课程元数据字段，数据库 `edu_course` 也已存在对应的文本列；但 `CourseServiceImpl` 只写入基础字段，未序列化并保存列表元数据，也未在详情转换中反序列化回填。因此前端详情收到空列表并显示默认值。课程详情还把 `videoUrl` 放在“课程资源”内，而“视频资源”读取前端占位数组；关联药材和课题同样是未连接后端的占位数组。

## 实施方案

### 1. 课程元数据保存与详情回填

- 后端将适用专业、教学目标、教学方式、标签保存为 JSON 字符串到现有 `TEXT` 列，并在详情接口解码为字符串数组。
- 先修课程保存为已发布课程的 ID 数组；详情返回 `prerequisiteCourseIds` 与可读课程名称列表。创建或更新时验证每个 ID 存在、启用、已发布，并排除当前课程。
- 对历史空值、空字符串或旧格式数据返回空列表，不阻断已有课程详情。

### 2. 课程资源与视频分栏

- 课程文件继续复用现有 `CourseResource` 绑定接口；普通资源只显示非 `video` 类型文件。
- 课程视频由主视频地址和类型为 `video` 的资源共同组成视频列表；详情页视频标签只渲染可播放视频，不再显示普通文件。
- 编辑页的普通文件上传固定为课件/讲义等文件类型；视频上传固定为视频类型，已有资源在对应分栏中显示和删除。

### 3. 真实关联数据

- 复用现有 `rel_course_species` 保存课程与药材的多对多关系。
- 复用现有 `rel_project_course` 保存课程与课题的多对多关系；由课程端维护时同步替换该课程的关联集合。
- 新增课程关联读取与更新接口，返回药材、课题的 ID、编号和名称；关联选择弹窗使用这些真实候选数据，保存后立即刷新详情。
- 不再渲染“关联采集数据”的空占位；本次仅实现用户明确要求的药材与课题关联。

### 4. 前端交互与权限

- `CourseEditorModal`：先修课程改为可搜索多选；课程标签改为可输入标签；资源、视频分栏管理。
- `CourseDetailPanel`：资源、视频、关联信息分别按真实数据渲染；有编辑权限时在关联信息标签页显示“编辑关联”按钮。
- `TeachingPageClient`：将 `edu:course:update` 贯通到详情面板；保存后刷新当前详情和课程列表。
- 后端控制器与服务层同时校验 `edu:course:update` 和课程归属，不能仅依赖前端隐藏按钮。

## 测试与验收

- 后端单测覆盖：元数据 JSON 往返、先修课程发布状态校验、自身排除、教师越权被拒绝、管理员可编辑、关系替换与详情回填。
- 前端回归覆盖：表单使用多选先修课程和标签控件；资源/视频分栏；关联信息调用真实接口；无编辑权限时不出现编辑按钮。
- 执行 `mvn.cmd test`、前端类型检查、`pnpm.cmd lint`、`pnpm.cmd build` 和相关 Node 回归测试；通过后再进行浏览器运行时核验。

## 不在本次范围

- 不改课程发布状态机、学生选课或实验记录业务。
- 不新增课程版本管理流程；已发布课程现有不可直接编辑规则继续生效。
- 不重写教学页布局或共享导航。
