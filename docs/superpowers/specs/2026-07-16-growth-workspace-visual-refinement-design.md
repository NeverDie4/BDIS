# 生长数据工作台视觉优化设计

## 目标

在不修改现有组件功能名称、接口调用、权限判断、状态管理和交互逻辑的前提下，统一生长数据页面与中药材资源页、分布地图页的本草标本馆视觉语言，重点优化标题栏、工作区比例、筛选区、记录区和右侧详情区的布局与样式。

## 改动范围

- 页面范围仅限 `/growth`。
- 使用现有 `ModuleHeroBanner` 替换页面自绘标题栏，沿用默认背景图 `/images/herbs/herb-title-banner.png`。
- 调整主工作区左右栏比例、间距、边框、纸张底色和响应式断点。
- 压缩筛选区域的纵向占用，使记录表格成为左侧主视觉区域。
- 将右侧详情区改为扁平、紧凑的纸张档案样式，减少大圆角、渐变背景和悬浮卡片感。
- 保留右侧现有四个详情标签及其切换逻辑。

## 不改动范围

- 不修改组件、变量、函数、接口和权限名称。
- 不修改任务创建、发布、提交审核、审核处理、导出、溯源、二维码和证据链逻辑。
- 不修改筛选条件、表格字段、趋势图数据与空状态判断。
- 不新增标签、抽屉、弹窗或其他交互。
- 不修改导航栏、其他路由、后端与数据库。

## 视觉方案

### 统一标题栏

使用 `ModuleHeroBanner` 的紧凑模式，标题保持“生长数据”，说明保持现有业务含义，眉题采用中文本草档案语义。标题栏直接复用统一本草背景图，不再保留原自绘线条与插画占位结构。

### 工作区比例

桌面端采用左侧主工作区约 72%、右侧详情区约 28% 的双栏结构。左侧承载筛选、记录表格与趋势内容；右侧维持固定详情面板和独立滚动。中等宽度下切换为单栏，避免详情面板挤压表格；移动端保持自然文档流。

### 筛选与记录区

筛选区改为紧凑纸张工具栏风格，减少标题、输入框和按钮之间的空白。记录工作区使用细边框、低圆角和清晰表头，按钮功能、禁用条件、分页及表格字段全部保持不变。

### 详情区

保留“基础信息、指标数据、现场图片、地图与溯源”四个标签。详情标题、摘要、字段组、指标、图片和溯源信息通过细分隔线和留白建立层级，移除明显渐变卡片和过大的圆角。详情内容仍在固定栏内独立滚动，末端审核操作保持可访问。

## 响应式策略

- 宽屏：双栏工作台，左侧为主、右侧固定详情。
- 中屏：在内容最小宽度不足前切换为单栏，详情位于主工作区之后。
- 小屏：筛选项、按钮组和字段网格按一列或两列重排，不出现横向溢出。

## 验证标准

- 静态回归测试确认页面复用 `ModuleHeroBanner`，且现有详情标签交互结构仍在。
- 现有前端回归测试与单元测试全部通过。
- ESLint 无新增错误。
- Next.js 生产构建成功。
- 浏览器检查桌面、中等宽度和移动端布局，确认无横向溢出，详情栏滚动与标签切换正常。
