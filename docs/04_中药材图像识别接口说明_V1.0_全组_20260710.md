# 中药材图谱识别接口文档

> 版本：V1.0
> 日期：2026-07-10
> 适用范围：标准图谱特征提取、用户图片匹配、辅助 AI 识别和人工复核。

## 模块定位

图谱识别以本地图谱库和特征向量匹配为主流程，豆包视觉模型只在低置信度场景下作为辅助复核手段。人工复核是最终确认步骤。

## 业务流程

```text
上传用户图片 -> 保存 herb_image -> 提取 herb_image_feature
-> 读取 herb_atlas_feature -> 余弦相似度匹配 -> 保存 herb_image_match
-> 生成 herb_identification_result
-> 低置信度时调用豆包并保存 herb_image_recognition
-> 人工复核确认
```

## FastAPI

### 提取特征

`POST http://localhost:8002/extract-feature`

```powershell
curl.exe -X POST "http://localhost:8002/extract-feature" -F "file=@D:\BDIS\ai_service\test.jpg"
```

返回字段：`success`、`featureVector`、`dimension`、`modelName`、`modelVersion`、`message`、`elapsedSeconds`。

### 豆包识别

`POST http://localhost:8001/recognize`

```powershell
curl.exe -X POST "http://localhost:8001/recognize" -F "file=@D:\BDIS\ai_service\test.jpg"
```

## Spring Boot 核心接口

### 上传用户图片

`POST /api/herb/image/upload`

```powershell
curl.exe -X POST "http://localhost:8080/api/herb/image/upload" `
  -F "file=@D:\BDIS\ai_service\test.jpg" `
  -F "speciesId=1" `
  -F "uploadSource=web" `
  -F "collectorId=1"
```

### 批量提取标准图谱特征

`POST /api/herb/atlas/feature/batch-extract`

```powershell
Invoke-RestMethod -Method POST `
  -Uri "http://localhost:8080/api/herb/atlas/feature/batch-extract" `
  -ContentType "application/json" `
  -Body '{"speciesId":null,"forceRefresh":true}'
```

### 提取用户图片特征

`POST /api/herb/image/{imageId}/feature/extract`

```powershell
Invoke-RestMethod -Method POST -Uri "http://localhost:8080/api/herb/image/4/feature/extract"
```

### 本地图谱匹配

```powershell
Invoke-RestMethod -Method POST `
  -Uri "http://localhost:8080/api/herb/image/4/match" `
```

```powershell
Invoke-RestMethod -Method POST `
  -Uri "http://localhost:8080/api/herb/image/4/identify" `
  -ContentType "application/json" `
```

`GET /api/herb/image/{imageId}/identification/latest`

```powershell
Invoke-RestMethod -Method GET -Uri "http://localhost:8080/api/herb/image/4/identification/latest"
```

### 人工复核

`PUT /api/herb/identification/{id}/review`

```powershell
Invoke-RestMethod -Method PUT `
  -Uri "http://localhost:8080/api/herb/identification/1/review" `
  -ContentType "application/json; charset=utf-8" `
  -Body '{"finalSpeciesId":1,"reviewStatus":"confirmed","reviewComment":"人工确认该图片为党参"}'
```

`reviewStatus` 只允许 `confirmed` 或 `rejected`。确认识别结果时必须提供有效的
`finalSpeciesId`；最终药材名称和复核人身份由服务端根据数据库记录及当前登录用户生成，
客户端不得提交或覆盖。

## 阈值规则

```text
similarity >= high-threshold: matched，不需要人工复核
middle-threshold <= similarity < high-threshold: uncertain，需要人工复核
similarity < middle-threshold: low_confidence，调用豆包辅助后仍需人工复核
```

## 检查 SQL

```sql
SELECT COUNT(*)
FROM herb_atlas_feature
WHERE is_deleted = 0
  AND extract_status = 'success';

SELECT image_id,
       remark AS match_batch_no,
       created_at AS match_time,
       match_rank,
       match_level AS match_result,
       image_similarity AS similarity_score
FROM herb_image_match
ORDER BY created_at DESC, match_rank ASC
LIMIT 10;
```
