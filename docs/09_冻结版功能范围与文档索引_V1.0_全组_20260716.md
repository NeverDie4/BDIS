> 负责人：全组

## 1. 目的与使用方式

本文档说明当前仓库在代码冻结阶段已经纳入交付范围的能力、明确不纳入本期交付的边界，以及不同文档发生冲突时的取舍顺序。它不是新的需求清单，也不替代接口、数据库或专项设计文档。

当前事实来源优先级如下：

1. 后端 Controller、OpenAPI（`/api/v3/api-docs`）与自动化测试。
2. `backend/src/main/resources/db/migration` 中已发布的 Flyway 脚本。
3. 本文档列出的专项接口/设计说明。
4. 通用需求、模块设计、数据库和接口规范。
5. `docs/deprecated/` 中的历史材料，仅用于追溯，不得作为实现依据。

## 2. 冻结版已纳入范围

| 业务域 | 已交付能力 | 说明 |
| --- | --- | --- |
| 账户、权限与会话 | 登录、退出、当前用户、角色权限、数据范围、access/refresh token 轮换与会话撤销 | 普通业务接口仍由后端做权限和行级范围校验。 |
| 中药材资源与地图 | 药材、基地、区域/字典、地图点位、图谱与识别服务接入 | AI 服务能力依赖本地或部署环境的配置与可用服务。 |
| 生长采集与溯源 | Web/移动端采集、审核、图片和材料、二维码公开溯源、数字生命档案 | 公开页面只展示满足公开条件的数据。 |
| 教学科研与培训 | 实验课程、课题研究、实验记录、培训计划、参与记录、反馈与统计 | 具体入口及角色可见范围以实际权限码和后端校验为准。 |
| 评价申报 | 评价任务、指标体系、申报档案与审核流程 | 归档和材料访问继续走统一文件权限策略。 |
| 业绩认定 | 业绩草稿/提交/审核、参与人、佐证材料、标准版本与快照、统计 | 详见业绩认定专项说明。 |
| 文件与审计 | 私有文件访问、业务文件关联、访问/操作/同步日志 | 不开放物理上传目录的运行期直读。 |
| SOAP 演示 | 本地 mock 校内生长记录服务、同步任务、交换留痕、幂等导入与一键演示脚本 | 默认关闭；仅证明对接链路，不等同于真实校内系统联调。 |
| 项目展示 | 门户首页、各业务入口及“关于我们”页面 | 页面展示不替代后端权限校验。 |

## 3. 本期明确边界

1. 不接入真实校内 SOAP 地址、真实凭据或真实校内系统；演示仅可使用显式开启的本地 `mock` 模式。
2. 不在冻结期新增业务表、重写已执行的 Flyway 迁移、扩大角色权限或改变既有业务状态机；仅接受阻断性缺陷、安全问题和文档勘误修复。
3. AI 识别、特征提取和大模型能力为可配置集成，未配置服务或密钥时不承诺真实识别结果。
4. 当前 refresh token 仍存储于 Web 和移动端本地存储；迁移为 HttpOnly Cookie/BFF 是后续安全演进项，不纳入本期。

## 5. 冻结期文档维护规则

1. 接口、迁移、配置或已交付流程确有变化时，必须同步更新对应专项文档，并在本文档索引中保持可定位。
2. 已完成的实施计划、代码审查修复草稿和未勾选的开发清单移入 `docs/deprecated/`，保留历史但不参与当前设计决策。
3. 新正式文档使用“编号_文档名称_V版本号_负责人_日期”命名；临时过程材料不得伪装为正式设计依据。
4. 任何涉及已发布 Flyway 脚本的说明，以脚本文件和基线 SHA-256 校验为准；不得通过改写文档或哈希掩盖历史迁移变化。
